# 文档翻译 0.1.8

解压 Release 中的 macOS ZIP，将 `DocTranslator.app` 拖入「应用程序」目录后打开。已有本机安装位于 `~/Applications/DocTranslator.app`；从源码构建时产物位于 `macos/dist/DocTranslator.app`。应用内含 Python 和文档引擎，无需终端或额外应用密码。

## 开始使用

1. 点击 **API 设置**（`⌘,`），填写兼容 OpenAI Chat Completions 的服务地址、模型和 API Key，保存后点击 **测试已保存配置**。连接测试会发送一个简短请求。
2. 点击 **导入文档**（`⌘O`），选择 PDF、DOCX、PPTX 或 XLSX，也可多选、拖入窗口或从 Finder「打开方式」导入。单个文件最大 100 MB。
3. 选择模型和目标语言，点击 **开始翻译**。可取消后继续；续翻使用该任务最初保存的模型和语言，已完成段落会保留。
4. 在 **段落对照** 中并排阅读原文和译文。点击译文修订，再点击 **保存到译文** 或 **保存全部草稿**。草稿自动保留，保存失败也不会清空。
5. 点击 **导出译文**，选择保存位置。有草稿时，可选择先保存全部，或仅导出已保存版本。导出格式与原文件相同。

## 阅读与历史

- **页面预览**支持缩放、翻页及输入页码；阅读视图、页码和段落位置会在切换文档及重启后恢复。
- 侧栏可搜索和筛选文档，上下方向键可切换；`⌘F` 可查找当前文档的原文、译文和草稿。
- **归档文档**保留内容和进度，在「已归档」筛选中可恢复。桌面版不会自动清除旧文档。
- 退出时保存已完成的翻译批次。未开始的导入会停止，重开后可重新选择文件。

## 已验证与限制

- 已用本地模拟 API 验证四种格式的导入、翻译、修订、导出重开，以及取消续翻、退出恢复、API 错误和保存失败处理。
- 已验证独立目录中的签名应用可启动，退出后其内置引擎结束。后端和打包测试 168 项、原生测试 46 项通过；4 项因缺少上游样例跳过。
- **真实服务连通性和翻译质量尚未验证**，需在应用内配置 API 后检查。
- PDF 可直接预览；Office 页面预览需要本机安装 LibreOffice。未安装时，段落阅读、翻译和导出仍可使用。
- 扫描 PDF 需要先做 OCR。复杂版式、公式、混合文字样式、图表及图片可能无法完全保真。PDF 译文放不下时会保留该位置原文，并给出排版提示；可缩短译文后重新保存。
- 当前为这台 Apple Silicon Mac 的自用签名版本，实际验证系统为 macOS 27.2；声明最低 macOS 14，尚未做其他机器验证、Developer ID 公证或 App Store 分发。

数据、配置、草稿和日志位于 `~/Library/Application Support/DocTranslatorMac/`。移动或更新应用不会清除这些文件。API Key 优先保存在 macOS 钥匙串，无法使用时退回本机加密存储。

源码构建、详细变更和验收记录见 [README](README.md)。
